# Robust Calculator

A command-line calculator built in Python, supporting standard arithmetic plus factorial, exponent, and remainder operations, with input validation and error handling for invalid operations and edge cases (e.g. division by zero).

## Features

- Addition, subtraction, multiplication, division
- Exponentiation
- Remainder (modulo)
- Factorial
- Input validation with clear error messages
- Graceful handling of invalid input and edge cases (e.g. division/modulo by zero, negative factorial input)

## Getting Started

### Prerequisites

- Python 3.x installed

### Running the Calculator

```bash
python "robust calculator.py"
```

Follow the on-screen prompts to select an operation and enter your numbers.

## Example

```
Select an operation:
1. Add
2. Subtract
3. Multiply
4. Divide
```
