# Log Analyzer

A simple Python command-line tool that analyzes log files and summarizes log activity.

## Features

- Counts INFO, WARNING, and ERROR entries
- Calculates the error rate
- Finds the most common error
- Displays an error breakdown
- Handles missing log files
- Supports JSON outputs for machine readable results
- Include automated tests

## How to Run

```bash
python log_analyzer.py sample.log
